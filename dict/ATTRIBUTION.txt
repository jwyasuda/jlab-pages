JMdict Simplified
-----------------
The JSON representation of JMdict used in this project is produced by the
jmdict-simplified project, maintained by Dmitry Shpika. This project parses the
original JMdict XML and converts it to a machine-readable JSON format.

  https://github.com/scriptin/jmdict-simplified
  MIT License — Copyright (c) Dmitry Shpika
